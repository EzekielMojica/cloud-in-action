Architecture

Under the Hood: How This Runs on AWS

Understanding serverless edge architecture on S3 Free Tier.

Plain English

The Digital Library

Think of a traditional web application like a physical bank. Every time you ask a question or upload a file, a "bank teller" (a backend server) has to take it to the back room, process it, and hand you a result. This costs money and introduces security risks.

AWS S3 Static Hosting is like a digital library. Amazon simply hosts this tool as a single "booklet" on a shelf. When you visit the site, your browser checks out the booklet and does all the reading, organizing, and formatting locally on your own laptop.

Because there is no bank teller running in the background, your data never leaves your computer, and the hosting cost is exactly $0.

Technical

Zero-Backend Edge Compute

This application utilizes a strict Client-Side DOM Processing Architecture. By leveraging browser Web APIs and JS libraries like Mammoth.js, the heavy compute load (parsing binary ArrayBuffers) is offloaded 100% to the edge client.

Because there are no EC2 instances, Lambda functions, or database endpoints attached to this S3 bucket, this architecture removes all traditional backend attack vectors. It enables infinite, concurrent scale while remaining well within the bounds of the AWS Free Tier.
